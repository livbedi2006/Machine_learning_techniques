## 1. What is a CSV File?

**CSV** stands for **Comma-Separated Values**. It is one of the simplest and most widely used formats to store **tabular data** (rows and columns) as plain text.

> **Definition:** A CSV file is a plain-text file where each line represents a row of data, and values within a row are separated by a delimiter (usually a comma).

```
name,age,city
Aman,25,Delhi
Riya,30,Mumbai
Karan,28,Bengaluru
```

**Why CSV is so common in Data Science/ML:**
- Lightweight and human-readable
- Supported by almost every tool (Excel, Pandas, SQL, Google Sheets, etc.)
- Easy to generate from databases, APIs, and exports
- Universal format for datasets on platforms like Kaggle, UCI, government portals

In Python, the **Pandas** library (`pd.read_csv()`) is the standard tool used to read, write, and manipulate CSV files for ML projects.

## 2. Reading a CSV File — Basics

```python
import pandas as pd

# Basic reading of a CSV file
df = pd.read_csv("data.csv")
print(df.head())      # shows first 5 rows
print(df.shape)        # (rows, columns)
print(df.info())       # column names, datatypes, non-null counts
```

| Function | Purpose |
|---|---|
| `pd.read_csv()` | Loads a CSV file into a Pandas **DataFrame** |
| `df.head(n)` | Shows the first `n` rows (default 5) |
| `df.tail(n)` | Shows the last `n` rows |
| `df.shape` | Returns `(number_of_rows, number_of_columns)` |
| `df.info()` | Summary — column names, data types, missing values |
| `df.describe()` | Statistical summary of numeric columns (mean, std, min, max, etc.) |

## 3. Important Parameters of `read_csv()`

`read_csv()` has many parameters that solve real-world messy-data problems. Below are the most important ones, explained with examples.

### 3.1 `sep` — Custom Delimiter
Not all "CSV-like" files use commas — some use tabs, semicolons, or pipes.

```python
# For a semicolon-separated file
df = pd.read_csv("data.csv", sep=";")

# For a tab-separated file (.tsv)
df = pd.read_csv("data.tsv", sep="\t")
```

### 3.2 `index_col` — Setting a Column as the Index
```python
# Use the "id" column as the row index instead of default 0,1,2...
df = pd.read_csv("data.csv", index_col="id")
```

### 3.3 `header` — Specifying/Removing Header Row
```python
# File has no header row -> assign default numeric column names
df = pd.read_csv("data.csv", header=None)

# Header is present on the 2nd line (0-indexed), not the first
df = pd.read_csv("data.csv", header=1)
```

### 3.4 `usecols` — Loading Only Specific Columns
Useful for large files where you don't need every column (saves memory).
```python
df = pd.read_csv("data.csv", usecols=["name", "age"])
```

### 3.5 `nrows` — Loading Only a Limited Number of Rows
Useful for quickly previewing a huge file without loading it fully.
```python
df = pd.read_csv("data.csv", nrows=1000)  # only first 1000 rows
```

### 3.6 `skiprows` — Skipping Specific Rows
```python
# Skip the first 2 rows (e.g., metadata/comments before actual data)
df = pd.read_csv("data.csv", skiprows=2)

# Skip specific row numbers
df = pd.read_csv("data.csv", skiprows=[0, 2, 5])
```

### 3.7 `encoding` — Handling Encoding Errors
Some files (especially with non-English text) throw `UnicodeDecodeError` with the default UTF-8 encoding.
```python
df = pd.read_csv("data.csv", encoding="latin-1")
# Other common options: "utf-8", "ISO-8859-1", "cp1252"
```

### 3.8 `dtype` — Forcing Specific Data Types
```python
# Force 'pincode' to stay as string (avoids losing leading zeros)
df = pd.read_csv("data.csv", dtype={"pincode": str})
```

### 3.9 `parse_dates` — Automatically Parsing Date Columns
```python
# Automatically converts "order_date" column into datetime format
df = pd.read_csv("data.csv", parse_dates=["order_date"])
```

### 3.10 `na_values` — Custom Missing Value Markers
By default, Pandas treats things like `NaN`, empty cells as missing. But real data often uses other placeholders like `"?"`, `"missing"`, `"-"`.
```python
df = pd.read_csv("data.csv", na_values=["?", "missing", "-", "N/A"])
```

### 3.11 `converters` — Applying a Custom Function While Reading
```python
# Convert "price" column values (e.g., "$500") into a float
df = pd.read_csv(
    "data.csv",
    converters={"price": lambda x: float(x.replace("$", "").replace(",", ""))}
)
```

### 3.12 `chunksize` — Reading Large Files in Chunks (Out-of-Core Style)
When a CSV file is too large to fit into memory at once, read it in smaller chunks.
```python
chunk_iter = pd.read_csv("huge_data.csv", chunksize=100000)  # 100k rows per chunk

total_rows = 0
for chunk in chunk_iter:
    total_rows += len(chunk)
    # process each chunk here (filter, aggregate, etc.)

print(f"Total rows processed: {total_rows}")
```

> This connects directly to the concept of **Out-of-Core Learning** covered earlier in the repository — `chunksize` is exactly how Pandas enables working with datasets larger than RAM.

## 4. Reading CSV from a URL

Pandas can read a CSV file directly from a web URL without manually downloading it first.
```python
url = "https://raw.githubusercontent.com/datasets/covid-19/main/data/countries-aggregated.csv"
df = pd.read_csv(url)
print(df.head())
```

---

## 5. Working with Compressed CSV Files

Pandas can directly read CSV files compressed as `.zip`, `.gz`, `.bz2`, etc., without manual extraction.
```python
df = pd.read_csv("data.csv.zip")     # auto-detects compression
df = pd.read_csv("data.csv.gz", compression="gzip")
```

## 6. Writing/Saving a DataFrame Back to CSV

```python
# Save DataFrame to a new CSV file
df.to_csv("output.csv")

# Save without the index column
df.to_csv("output.csv", index=False)

# Save only specific columns
df.to_csv("output.csv", columns=["name", "age"], index=False)

# Save with a different separator
df.to_csv("output.tsv", sep="\t", index=False)
```

## 7. Full Working Example — Putting It All Together

```python
import pandas as pd

# ------------------------------------------------------------
# Step 1: Create a sample "messy" CSV to simulate real-world data
# ------------------------------------------------------------
raw_data = """id,name,age,city,salary,join_date
1,Aman,25,Delhi,$50000,2021-01-15
2,Riya,?,Mumbai,$62000,2020-06-23
3,Karan,28,-,$58000,2019-11-02
4,Neha,32,Bengaluru,$71000,2022-03-10
"""

with open("employees.csv", "w") as f:
    f.write(raw_data)

# ------------------------------------------------------------
# Step 2: Read the CSV with multiple real-world fixes applied
# ------------------------------------------------------------
df = pd.read_csv(
    "employees.csv",
    index_col="id",                          # use 'id' as row index
    na_values=["?", "-"],                    # treat these as missing values
    parse_dates=["join_date"],                # convert to datetime
    converters={"salary": lambda x: float(x.replace("$", ""))}  # clean salary column
)

print(df)
print(df.dtypes)

# ------------------------------------------------------------
# Step 3: Save the cleaned DataFrame back to a new CSV
# ------------------------------------------------------------
df.to_csv("employees_cleaned.csv")
```

### Explanation of the Example

| Line | What It Does |
|---|---|
| `index_col="id"` | Uses the `id` column as the row label instead of a default 0,1,2 index |
| `na_values=["?", "-"]` | Converts placeholder symbols like `"?"` and `"-"` into proper `NaN` (missing) values so Pandas/ML models can handle them correctly |
| `parse_dates=["join_date"]` | Converts the `join_date` text column into an actual `datetime64` type, enabling date-based operations (e.g., extracting year, calculating tenure) |
| `converters={"salary": lambda x: ...}` | Cleans the `salary` column by removing the `"$"` symbol and converting it into a proper numeric (`float`) type, since raw salary strings can't be used in calculations |
| `df.to_csv(...)` | Persists the cleaned dataset to disk so it can be reused later without repeating the cleaning steps |

## 8. Quick Reference Summary

```
Reading CSV        → pd.read_csv("file.csv")
Custom delimiter   → sep=";"
Skip rows          → skiprows=N
Limit rows         → nrows=N
Select columns     → usecols=[...]
Fix missing values → na_values=[...]
Fix data types     → dtype={...}, converters={...}
Parse dates        → parse_dates=[...]
Handle big files   → chunksize=N
Read from web       → pd.read_csv(url)
Read compressed     → pd.read_csv("file.csv.gz")
Save to CSV         → df.to_csv("file.csv", index=False)
```

**Key takeaway:** In real ML projects, raw CSV files are rarely clean. Knowing the right `read_csv()` parameters saves significant time during the **Data Preprocessing** stage of the MLDLC, letting you handle messy delimiters, missing values, wrong data types, and oversized files efficiently — all directly from Pandas.
